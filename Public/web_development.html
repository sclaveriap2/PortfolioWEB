<p>Fuchsproperty.com es una pagina de compra y venta de propiedades, desarrollada utilizando wordpress, funciona como link de contacto entre posibles compradores y la empresa fuchs property</p>

<p>Originalmente la pagina fue desarrollada como proyecto estatico, utilizando html, css y javascript proyecto que fue almacenado en su propio repositorio en github</p>|

</div>

<p>Luego de desarrollada la pagina principal en html, se decidio por continuar el desarrollo utilizando wordpress, por la facilidad de mantención para el cliente post entrega.</p>

<div class="PORTFOLIO">

<p>Esta misma pagina, desarrollada como pagina estatica, utiliza el servicio de firebase para hosting con conexión directa a github a travez de github actions como CI/CD, para optimizar las actualizaciones y mantencion del proyecto</p>

</div>
